01Ce que tu es en train de faire, et pourquoi c'est la bonne méthode

Il y a deux façons de monter une boutique Shopify. Une qui te coûte des journées et des apps à 20 €/mois. Une qui tient en 2 à 3 heures par page. On prend la deuxième.

Les deux outils, en langage simple

Shopify CLI est un petit programme installé sur ton ordinateur. Il fait une seule chose : il connecte ton ordinateur à ta boutique Shopify. Grâce à lui, les fichiers de ton thème sont chez toi, dans un dossier, et tu peux voir chaque changement en direct dans une prévisualisation, sans toucher à la boutique que tes clients voient.

Claude Code est une IA à qui tu parles en français dans une fenêtre de commande. Elle lit les fichiers du dossier, comprend la structure du thème, et écrit le code à ta place. Tu ne tapes jamais une ligne de code. Tu décris le résultat, tu regardes l'aperçu, tu valides ou tu corriges. Si tu sais écrire un message WhatsApp, tu sais l'utiliser.

Tu travailles toujours sur une copie de développement du thème. Ta boutique publiée ne bouge pas tant que Mady n'a pas validé. Tu peux donc tout essayer, tout casser, tout recommencer : rien n'est visible des clients. Retiens cette phrase, elle revient dans chaque chapitre : jamais de theme push ni de theme publish sans consigne de Mady.

03Le dossier de travail et ton thème Aesthetic Lab

Tout se passe dans un seul dossier sur ton ordinateur. Le thème de ta boutique y est copié, Claude Code y travaille, Shopify CLI le prévisualise.

1

Crée le dossier BOUTIQUE-SHOPIFY

Dans Documents, crée un dossier nommé exactement BOUTIQUE-SHOPIFY. Pas d'espace, pas d'accent. C'est le seul dossier dont tu auras besoin pour toutes tes boutiques futures : une sous-dossier par boutique si un jour tu en as plusieurs.

2

Ouvre une fenêtre de commande directement dans ce dossier

Windows : ouvre le dossier dans l'Explorateur. Clique dans la barre d'adresse tout en haut, efface le chemin, tape cmd puis Entrée. La fenêtre noire s'ouvre déjà dans le bon dossier.

Mac : ouvre Terminal. Tape cd suivi d'un espace, fais glisser le dossier depuis le Finder dans la fenêtre Terminal, puis Entrée.

Vérifie : la ligne de commande affiche le nom du dossier. Si tu vois C:\Users\toi> ou ~ $ tout seul, tu n'es pas dans le bon dossier.

3

Trouve ton adresse .myshopify.com

Admin Shopify → Paramètres → Domaines. Repère l'adresse qui se termine par .myshopify.com, par exemple ma-marque.myshopify.com. Note-la dans un fichier texte : tu vas la taper dans chaque commande. Dans tout ce guide, remplace MA-BOUTIQUE.myshopify.com par ta vraie adresse.

4

Teste la connexion

shopify theme list --store MA-BOUTIQUE.myshopify.com

La première fois, Shopify ouvre ton navigateur : connecte-toi, choisis la bonne boutique, autorise Shopify CLI. Si une liste de thèmes apparaît dans la fenêtre de commande, ton ordinateur est connecté. Rien n'a été modifié.

Récupérer le thème Aesthetic Lab : trois cas, un seul résultat

Le but : avoir les fichiers du thème dans BOUTIQUE-SHOPIFY, avec les dossiers assets, config, layout, locales, sections, snippets, templates directement à la racine (pas dans un sous-dossier).

Ta situationCe que tu fais
Cas A. Mady a généré ta boutique et le thème est déjà sur ton Shopify (c'est le cas normal)Admin → Boutique en ligne → Thèmes. Le thème apparaît dans « Bibliothèque de thèmes ». Clique sur « … » → Publier (après accord de Mady). Puis récupère-le sur ton ordinateur avec la commande ci-dessous.
Cas B. Mady t'a envoyé un fichier aesthetic-lab.zipAdmin → Thèmes → « Ajouter un thème » → « Importer un fichier zip » → choisis le zip tel quel (ne le décompresse pas pour l'import). Ensuite, décompresse une copie du zip dans BOUTIQUE-SHOPIFY pour Claude Code.
Cas C. Tu veux repartir de ce qui est en ligneLa commande theme pull ci-dessous télécharge n'importe quel thème de ta boutique dans le dossier courant.

La commande qui télécharge le thème depuis ta boutique (lance-la dans BOUTIQUE-SHOPIFY) :

shopify theme pull --store MA-BOUTIQUE.myshopify.com

Shopify te demande quel thème : choisis « Aesthetic Lab » avec les flèches, Entrée. Attends la fin. Ouvre le dossier dans l'Explorateur ou le Finder : tu dois voir les sept dossiers listés plus haut.

Le sous-dossier fantômeSi en décompressant un zip tu obtiens BOUTIQUE-SHOPIFY/aesthetic-lab-template/assets/…, Claude Code et Shopify CLI ne trouveront rien. Déplace le contenu du sous-dossier à la racine de BOUTIQUE-SHOPIFY et supprime le sous-dossier vide.
✅ Fait quandshopify theme list affiche tes thèmes, et le dossier BOUTIQUE-SHOPIFY contient directement assets, sections, templates, config, layout, snippets, locales.

04Le cycle de travail : deux fenêtres, un aperçu, zéro risque

C'est le cœur de la méthode. Une fenêtre montre ta boutique en direct, l'autre parle à Claude. Tu alternes entre les deux toute l'après-midi.

1

Fenêtre 1 : la prévisualisation Shopify

Dans BOUTIQUE-SHOPIFY, lance :

shopify theme dev --store MA-BOUTIQUE.myshopify.com

Shopify crée un thème de développement (invisible des clients) et affiche un lien, en général http://127.0.0.1:9292. Ouvre-le dans Chrome. C'est ta boutique, version brouillon. Chaque fichier modifié par Claude Code se recharge tout seul dans cet onglet, en 1 à 2 secondes.

Ne ferme jamais cette fenêtre pendant que tu travailles. Réduis-la, c'est tout.

2

Fenêtre 2 : Claude Code

Ouvre une DEUXIÈME fenêtre de commande dans le même dossier (même manœuvre qu'au chapitre 03, étape 2), puis :

claude

Une interface de discussion s'ouvre dans la fenêtre. Tu tapes ton message, Entrée. Claude lit, réfléchit, propose des modifications de fichiers et te demande confirmation avant d'écrire. Réponds « oui » (ou « y ») quand tu es d'accord.

3

La boucle : décrire → regarder → valider ou corriger

  1. Tu décris ce que tu veux (en français, précis, un seul sujet par message).
  2. Claude modifie les fichiers et te dit quoi vérifier.
  3. Tu regardes l'onglet 127.0.0.1:9292, sur ordinateur ET en mode mobile (clic droit → Inspecter → icône téléphone, ou réduis la fenêtre).
  4. Ça te plaît : « Parfait, on passe à la suite. » Ça ne te plaît pas : tu dis exactement ce qui cloche (« le bouton passe sous l'image sur mobile », « le titre est trop petit », « la couleur n'est pas la bonne »).
La règle absolueN'utilise jamais shopify theme push ni shopify theme publish sans consigne de Mady. Le thème de développement est invisible des clients : tu peux tout y faire. Pousser, c'est remplacer ce qui est en ligne. Ça se fait une fois, ensemble, quand tout est validé.

Pourquoi deux fenêtres ?

La première garde la prévisualisation active : si tu la fermes, l'aperçu meurt et tu ne vois plus tes changements. La deuxième est la conversation avec Claude. Deux fenêtres, deux rôles. Beaucoup d'élèves lancent claude dans la fenêtre de theme dev : ça coupe l'aperçu. Si tu vois « Impossible de se connecter » dans Chrome, c'est ça.

Fin de session

Pour arrêter : dans chaque fenêtre, Ctrl + C (Mac : Ctrl + C aussi). Tes fichiers restent dans le dossier. La prochaine fois, tu relances les deux commandes et tu reprends où tu en étais. Claude Code garde même la mémoire du projet si tu tapes claude --continue.

✅ Fait quandTu as les deux fenêtres ouvertes, ta boutique s'affiche sur 127.0.0.1:9292, et Claude a répondu à un premier message.

05Les deux premiers prompts : onboarding et règles du jeu

Avant de construire quoi que ce soit, Claude doit lire ton thème et connaître tes règles. Deux messages, cinq minutes, et tout le reste de l'après-midi se passe bien.

Prompt 1 : l'onboarding (Claude lit, n'écrit rien)

Copie ce message tel quel dans la fenêtre Claude Code :

Tu es mon développeur Shopify. Ce dossier est le thème de ma boutique. Lis-le entièrement, puis dis-moi en 10 lignes : la structure de la page produit, les sections existantes, et ce que tu me conseilles de supprimer ou d'ajouter pour une page produit qui convertit. N'écris rien pour l'instant.

Claude te rend un résumé. Lis-le : tu apprends en deux minutes comment ton thème est construit (quelle section fait quoi). Garde ce résumé sous les yeux pour la suite.

Prompt 2 : les règles du jeu (valables pour toute la session)

À partir de maintenant, pour chaque section que tu crées : tout texte, image, couleur et prix doit être modifiable depuis l'éditeur de thème (schema settings). Mobile first. Pas de librairie externe. Couleurs : fond #FFFFFF, texte #111111, accent #006DBC. Après chaque section, dis-moi quoi vérifier dans l'aperçu.

Remplace les trois couleurs par celles de ta marque (tu les as choisies au guide 06, chapitre couleurs ; sinon prends celles que Mady a mises dans ton thème : demande à Claude « quelles sont les couleurs principales définies dans assets/base.css ? »).

Pourquoi ces règles comptent« Modifiable depuis l'éditeur de thème » : tu pourras changer un texte ou une image depuis Shopify → Personnaliser, sans revenir dans Claude Code. « Mobile first » : 80 % de tes clients arrivent depuis Instagram ou TikTok, sur téléphone. « Pas de librairie externe » : ta page reste rapide, et rapide = ça vend.
Demande à ClaudeTu ne comprends pas un mot du résumé (« snippet », « schema », « liquid ») ? Demande : « Explique-moi ce qu'est un [mot] dans un thème Shopify, en une phrase, comme à quelqu'un qui n'a jamais codé. » Tu n'as pas besoin de comprendre le code, juste le vocabulaire pour dialoguer.
✅ Fait quandClaude t'a rendu le résumé de ton thème et a confirmé les règles du jeu avec tes couleurs.

06Le prompt maître : la page produit entière en 11 sections

C'est le message qui construit ta page produit. Claude avance section par section et te demande validation à chaque étape. Compte 2 à 3 heures, aperçu ouvert.

Remplace [produit] par ton produit, puis colle :

Construis la page produit de [produit] avec ces sections, dans cet ordre, chacune dans son propre fichier sections/ :
1. Barre d'annonce avec compte à rebours et "Livraison offerte aujourd'hui".
2. Galerie avec miniatures, "4,8/5 · 1 300 avis" au-dessus du titre, prix barré + prix promo + badge "-46 %".
3. Promesse en gras + 6 bénéfices d'une ligne avec icône.
4. Sélecteur de bundle 1 / 2 packs (présélectionné, "le plus populaire", cadeau offert), bouton "Profiter de l'offre".
5. Garanties : livraison offerte, 30 jours satisfait ou remboursé, paiement sécurisé.
6. FAQ accordéon 5 questions.
7. Grille de 4 bénéfices.
8. 3 statistiques en gros chiffres.
9. Tableau comparatif nous vs 2 alternatives, 5 critères.
10. 6 avis clients en cartes.
11. Bloc garantie pleine largeur.
Ajoute chaque section au template product.json. Textes en français, placeholders réalistes. Commence par la section 1, montre-moi, puis enchaîne.

Comment se passe la construction

  • Claude crée la section 1, modifie templates/product.json, et te dit : « Vérifie la barre d'annonce en haut de la page produit, sur mobile le texte doit tenir sur une ligne. »
  • Tu ouvres une page produit dans l'aperçu (127.0.0.1:9292/products/ton-produit). Tu regardes. Tu réponds « OK, enchaîne » ou tu décris la correction.
  • Il passe à la section 2, et ainsi de suite. Onze fois.
Ce que tu obtiensLa structure exacte de la page analysée au guide 05 (Crystal Hair Eraser, bleame.com) : preuve avant le titre, promesse, bundle présélectionné, garanties, puis chaque objection levée dans l'ordre. Les textes sont des placeholders réalistes : tu les remplaces par les tiens au guide 05 (ou tu demandes à Claude de les écrire, prompt fourni là-bas).
Si Claude part dans tous les sensUn message = une section. S'il te propose de tout faire d'un coup, réponds : « Non. Une section à la fois, montre-moi, j'attends ma validation avant la suivante. » S'il bloque sur une erreur, copie-lui le message d'erreur complet de la fenêtre theme dev : il corrige.

Les sections pas à pas, en détail

Si tu préfères construire la page section par section, ou en ajouter une plus tard, voici les prompts unitaires de Mady. Copie, colle, adapte le nom du produit.

Bundle

Crée la section "bundle-selector" : 3 options (1, 2, 3 unités) en cartes radio, prix unitaire, prix total, économie en %, badge "Le plus populaire" sur l'option 2 présélectionnée. Le bouton ajoute la bonne quantité au panier.

Tableau comparatif

Crée la section "comparison-table" : colonne critères, colonne notre produit surlignée, 2 colonnes alternatives. 5 lignes, chaque cellule = coche verte ou croix rouge choisie dans l'éditeur. Lisible sur mobile.

Avant / après

Crée la section "before-after" : deux images avec un curseur glissant pour comparer, labels modifiables, titre et sous-titre. Fonctionne au doigt sur mobile.

Sticky add to cart

Ajoute une barre fixe en bas d'écran mobile après 400px de scroll : miniature, prix promo, bouton "Ajouter au panier". Disparaît quand le bouton principal est visible.

Avis clients

Crée la section "reviews-grid" : 6 cartes avec étoiles, titre, texte, prénom + initiale, badge "Achat vérifié". Chaque avis est un bloc modifiable. Note globale en en-tête.

FAQ

Crée la section "faq-accordion" : questions en blocs modifiables, une seule ouverte à la fois, icône + / −. Ajoute le balisage schema.org FAQPage.
✅ Fait quandLes 11 sections sont visibles dans l'aperçu, dans l'ordre, sur ordinateur et sur mobile, et tu peux changer un texte de chaque section depuis Shopify → Personnaliser (sur le thème de développement).

07Et aussi, en une phrase : les prompts du quotidien

Une fois la page construite, 90 % de ce que tu feras tient en un message. Voici ceux que Mady utilise toutes les semaines.

Nouveau produit en 10 minutes

Duplique le template de page produit de [produit A] en "product.b" pour [produit B]. Remplace les textes par ceux-ci : [textes]. Garde structure, couleurs et sections identiques.

Ensuite, dans Shopify : Produits → le produit B → « Modèle de thème » → choisis product.b. Le deuxième produit a sa page complète, sans tout reconstruire.

Traduire la boutique

Traduis tous les textes des sections de la page produit en anglais américain, ton casual, dans locales/en.default.json, sans toucher au code.

Corriger un bug mobile

Sur mobile, le bouton du bundle passe sous la galerie. Trouve la cause et corrige sans changer le design desktop.

Adapte la première phrase à ton bug : décris ce que tu vois, où, sur quel appareil. Une capture d'écran collée dans la fenêtre (Ctrl + V) aide énormément.

Vitesse

Liste ce qui ralentit la page produit : images, scripts, apps. Applique les corrections sans risque, dis-moi ce qui demande ma validation.

Page d'accueil

Crée une page d'accueil produit unique : hero plein écran, 3 bénéfices, 3 avis, garantie, FAQ. Réutilise les sections déjà créées.

Mettre en ligne (avec l'accord de Mady seulement)

Vérifie l'aperçu, puis pousse le thème comme thème non publié. Je le publierai moi-même depuis Shopify.

Claude lance shopify theme push --unpublished : le thème arrive dans ta bibliothèque Shopify, SANS remplacer celui en ligne. Tu l'envoies à Mady, il valide, et c'est toi qui cliques « Publier » dans Thèmes. C'est la seule façon de mettre en ligne dans l'accompagnement.

08Bien parler à Claude Code (et à Claude dans Chrome)

Claude est aussi bon que ce que tu lui donnes. Trois habitudes font toute la différence : le contexte, les captures, et la validation à chaque étape.

Donne le contexte en entier

Au début d'une session, dis-lui qui tu es et ce que tu veux. Exemple :

Je lance une boutique Shopify de [produit] pour [cible : qui, âge, besoin]. Je suis sur [Windows / Mac], je ne sais pas coder, je travaille avec le thème Aesthetic Lab et je suis la méthode de mon coach. Aujourd'hui je veux [objectif précis : ex. finir la page produit et corriger l'affichage mobile]. Guide-moi étape par étape, fais-le pour moi quand tu peux, et dis-moi quoi vérifier dans l'aperçu après chaque modification.

Montre, ne décris pas

  • Une erreur : copie le message complet de la fenêtre theme dev ou de Claude Code, colle-le. Pas « ça marche pas ».
  • Un problème visuel : capture d'écran de l'aperçu, collée directement dans la fenêtre Claude Code (il lit les images).
  • Une référence : « Je veux un bundle comme sur [lien de la page concurrente], section juste sous le prix. »

« Montre-moi, puis enchaîne »

Termine chaque grosse demande par cette phrase. Claude fait une étape, s'arrête, tu vérifies, il continue. Sans ça, il peut modifier dix fichiers avant que tu aies vu quoi que ce soit. Avec ça, tu gardes le contrôle sans ralentir.

L'extension Claude pour Chrome : pour l'admin Shopify

Claude Code travaille dans les fichiers du thème. Pour tout ce qui se passe dans l'admin Shopify (paiements, livraison, taxes, politiques, Pixel), installe Claude pour Chrome (claude.ai/chrome). Il prend la main sur ton navigateur : il clique, remplit, vérifie, pendant que tu regardes.
